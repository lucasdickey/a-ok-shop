This is a NextJS app with an embedded game imported from another repo we own (v0-retro-style-game-concept) and a service call to the self-replicating art API.

The game, Run, Human, Run!, is a Pac-Man-style maze chase: the human collects UBI credits, dodges the apes, and eats Touch Grass pellets to turn the apes edible for a few seconds. It is drawn on a canvas; the rules live in `app/modules/game/engine.ts` and the player moves with arrow keys or WASD.

**NEW: Game Reward System**
The game now features a discount code reward system. When players win the game (collect 10 UBI credits; 3 on a local dev server), they are presented with an overlay containing a 25% discount code for the A-OK Store. The discount system creates real single-use Stripe promotion codes when Stripe is configured, and mock codes in development.

This app is a proof of concept for a potential future product where users can purchase a t-shirt with a unique design that is generated by the self-replicating art API. The design will be generated based on the user's preferences and the design will be unique to each user.

Product and catalog data (including images and metadata) comes from the bundled `product-catalog.json`. The cart is kept in the browser, and checkout, prices, and discount codes run through Stripe. Every tee and hoodie is printed on demand in sizes XS–2XL (`app/lib/sizes.ts`).

The game and the ImageGrid Chaos Monkey images are a proof of concept for more content and interaction in a retail setting.

## Key Features:

1. **Game Integration**: Pac-Man/Snake hybrid game with reward system
2. **Discount Code Generation**: Win-based discount code system (/api/discount)
3. **Stripe Integration**: Checkout, catalog prices, and discount codes
4. **Responsive Design**: Works on desktop and mobile
5. **Self-Replicating Art**: Dynamic image generation and gallery
