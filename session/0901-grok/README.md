## TL;DR

Cursor's five concepts cluster around **digital chrome** (terminal, glitch, arcade, particles) plus one **fashion editorial**. That's a strong spread, but it undersells three things already in the brand:

1. The **wheatpaste / street-poster art** already in the gallery
2. The **Keys** in Apes On Keys (studio / hardware, not just CLI)
3. **Product photography** as the hero, not CSS decoration

This pass adds five directions that do not retread 01–05. Fastest compare: open the local index and read both rows.

**Recommended next step (this pass):** Prototype **08 Research Issue** as the system, with **06 Wheatpaste** energy in the gallery/hero collage. If you want maximum distinctiveness over conversion, start with **10 Supergraphic** instead.
